# v0.2 规则与实现边界

## 目标

从“每个人什么都能做，平 A 赢大部分战斗”转成信息透明的资源与回合选择。
参照玩家提出的 Etrian Odyssey 式队伍职责与 GBF 式预兆交互，但不复制名称、素材、
具体敌人或完整商业系统。技能/敌人描述是规则提示，不是未实现的设计承诺。

## 冒险与经济

1～3 个不同职业，五层。从零开始，没有永久属性、职业等级或继承武器。
有种子 RNG，每次状态保存包含 RNG，读取/绘制本身不消耗它。
战胜小队、开箱、祭坛给三选一；只取一项。
一项优先从当前可学技能/觉醒中抽取，一项祝福，第三项熟练度或武器；宝箱/精英/祭坛第三项武器。
这不是“所有奖励同时拿到”，也不保证某一特定职业每层抽中指定技能。
独行巫女第一宝箱额外保证提供月光裁决，仍需玩家选择该卡。

每职业 2 起手 + 3 高阶；后者 B1/B2/B3 分段进池，属于该角色而不是队伍共用。
起手熟练度 +1 后加入机制觉醒。熟练度最多 +2，伤害/治疗每级 12%；支援降低 MP，
血契提高回蓝。觉醒状态单独存储，不占武器效果，也不跨局继承。
祝福各自有 cap；武器数值随层数小幅增长，但固有效果仍然只一个。

基础普攻回 1 MP；防御回 3 MP、至自身下次行动直接承伤 ×0.35。
战后每人 2% HP + 1 MP；倒地者先恢复 10% HP，再获得战后恢复。
升级 HP 上限 +5、MP 上限 +2、职业主属性 +1；仅补新增上限，骑士每偶数级防御 +1。
休息/泉水一次性。三类共享补给开局 3/2/2，下一层 +2/+1/+2，分别上限 5/4/4。
它们消耗行动，是缺乏对应职业时的有限反制手段，而不是每个职业自带完整治疗。

## 时间、地图与视野

DFS 格子地牢 + 四个区域房间 + 环路 + 长廊；B1 15×15、B2–3 17×17、B4–5 19×19。
四个区域锚点的近邻划分决定地面/墙面材质。各区都有固定类别地标和 Roman 编号。
同一层存在不同大小开放房间；不是每个墙格都换随机颜色。

每层放置约 7+层数个小队（满足空位/间距时），其中一个精英；无无限刷新。
玩家成功移动或 Space 等待：世界 tick +1，每个未交战小队最多走一格。
距离玩家 5 格路径以内追逐，其他巡逻；每个战斗回合末仅路径 8 格内小队推进。
格子占用可能使小队等待，最短距离不是保证抵达时间。转向、撞墙、读图、暂停不推进。
近处直线视野展示实际敌人，探索地图上标记已探索位置的敌方小队；隔墙不显示精确未探位置。
声音给出附近未知脚步与最短距离。实体碰撞发起战斗，没有概率暗雷。

小队抵达战斗格子后进入战斗列表，`readyRound = currentRound + 1`；不插队偷袭。
最多 6 个存活敌人，整队装不下时在格子上等待。击杀最后敌人仍先结算一次世界移动，
因此不能靠击杀结算跳过已经到门口的增援。撤退保留伤势和有限整顿时间，不给经验。

## 战斗结算

每轮重排速度序列；玩家一个角色动作后自动推进至下个玩家动作。
先手速度和敌人意图公开；迟缓/加速主要改变下一轮顺序。群体/单体目标分别验证。
错误的所有权、目标或资源请求不会扣 MP、消耗补给、推进回合或消耗 RNG。

封头压制法术/治疗/强化/召唤，封腕压制重击/猎杀/物理群攻/护卫等。
被封印的原动作当轮变为低效攻击，不延后补发。不可在尚未解除时反复刷新同部位，
解除后至 `当前回合 + 2` 抵抗同部位。封印不会普遍取消所有 Boss 预兆。
燃烧/毒按施术者属性设定固定伤害，不按首领生命比例造成伤害。
破甲、星标、弱点、融解、技能联携与忍者追击可配合；普攻不积攒技能联携。

## 首领预兆

每个首领有一套独有强化/条件。首次定时预兆 R3，后续间隔见数据；HP 阈值一次性。
血线命中只排入队列，等下个没有占用的回合开始再预告，给予完整玩家响应窗口。
当前预兆在指定回合末结算，多个血线不在同一击中无预告连续爆发。
跨线伤害截在该阈值，最后 1 HP 受尚未结算的 HP 预兆保护；界面和日志明确解释相位锁。
这是 v0.2 有意的反跳阶段规则，不是所有 GBF 战斗的普遍规则。

| 应对类型 | 实际条件 |
| --- | --- |
| 防护 | 不取消；防御、壁垒、拦截、护盾降低这一轮群体伤害。 |
| 驱散 | 当前首领的仪式结界被移除，预兆取消。驱散优先结界，不被普通 buff 挡住。 |
| 封印 | 首领结算时仍被封头，或者仪式结界已被驱散。 |
| 命中 | 当次窗口对首领的直接命中 ≥ 队伍人数 +1；多段、武器回响与反击分别计数。 |
| 侍从 | 当次预兆召唤的仪式侍从全部死亡；不是要求清空后来所有普通增援。 |

取消后首领获得两次行动破甲/衰弱；未取消会造成 2.65 倍攻击/魔力的群体打击，
特定首领额外中毒、迟缓、自愈或狂热。可驱散/不可驱散状态有明确区分。
术士延期只给当次预兆一次额外回合，不删除条件、不消除其他血线队列。
R13 开始首领伤害逐轮 +12%，避免无限防御恢复资源。

B1 月铠抵抗物理，可破甲/驱散；B2 荆棘反甲反制乱砍；B3 魔镜压制法术；
B4 初始加速强调行动节奏；B5 结合驱散、仪式与多段窗口。详见 `BOSS_SPECS`。

## UI、存储与已知限制

预兆面板显示来源、回合期限、解除方法、即时完成进度；旁边提示近处增援距离。
动态技能按钮按习得状态生成；支援技能选择队友，群体觉醒不再要求单选。
手机展示技能规则，不只依赖 hover；六敌人横向滚动选择。
默认舒适视角即时移动/转向，无摇头/呼吸晃动、闪屏、漂浮粒子；可切换平滑模式。
四区材质不是四种不同的迷宫生成算法，当前还没有机关地形、前后排或完整子职业系统。

序列化恢复战斗时重新链接地图小队成员与战斗实体，保持逃跑后生命和新来的增援一致。
v1 和 v2 使用不同存储 key；不迁移旧局。浏览器原生 `file:` 存储策略因平台而异。
只有固定种子测试/策略诊断，不表示完成长期平衡，也不保证全部独行职业/种子可通关。
