# v0.2.1 探索表现修复

## 使用

本轮源码与 `dist/index.html` 一起交付。下载静态页即可离线运行，不开启公开托管。
标题版本更新为 0.2.1，战斗、职业、奖励和地图生成规则没有改动。
仍使用 `eclipse-labyrinth.run.v2`，旧 v0.2 的游戏状态可恢复，不要求重开一局。
是否能直接读取旧文件的本地存储取决于浏览器与打开位置，不能把格式兼容等同于文件间自动迁移。

菜单新增「物件动画」：默认关闭，单独开启后浮游敌人轻微上下移动、地面敌人微幅呼吸，
星灯火焰/泉水亮度变化。舒适镜头可以保持开启；操作系统「减弱动态」覆盖动画开关。
没有增加摇头、呼吸镜头、转向惯性或屏幕闪烁。

## 根因与修复（P1）

旧代码把仅有 `viewBox`、没有显式宽高的 SVG 直接传给 `drawImage` 九参数裁切形式，
然后用 `naturalWidth/naturalHeight` 逐列计算源坐标。复现环境中，旧史莱姆 SVG 的
自然尺寸为 160×150，内部视图为 320×300；完整绘制正常，逐列绘制只留下放大、截断的部分。
它不是需要把 billboard 换成立体模型才能解决的问题，上一轮「只是占位贴片/朝向问题」的解释不准确。

新方案：探索资源显式为 320×320 → 加载后完整绘制到透明 Canvas 缓存 →
根据墙的深度缓冲合并可见屏幕列 → 对完整位图做裁剪蒙版后绘制。
不再对 SVG 逐条切源图；不靠放宽深度判定把物体强行画到墙前。
缓存还计算实心轮廓边界，使名称靠近实体，而不是悬在透明留白上方。

宝箱使用箱盖、金属包边与锁扣；阶梯使用门框、收缩台阶与下行箭头；祭坛为月像和台座。
泉水、星灯也有独立轮廓。加入分面明暗、描边和投影，颜色并不是唯一识别依据。

## 敌群和远距信息（P2）

10 个敌人类型均有探索图像。荆棘甲兽、折光晶核、召唤祭司与月门守卫有新剪影，
不再仅用同一种外形换色。队伍展示队长和最多两个后排剪影；撤退后只展示实际存活成员。
普通敌群为菱形标记，精英为金色冠形、更大轮廓；关闭月门前显示守卫/最终首领，
击败守卫后换成开放的下行阶梯。可见距离内的远处目标附紧凑标记，不显示隔墙图标。
标记避免互相重叠，并避让原有标题、罗盘、调查按钮和底部说明。空间不够会隐藏低优先级标记。

## 深度、动画和装饰（P3）

这是继续使用 raycasting 的 2.5D 方案，不是换成 WebGL 或真正可绕行的三维模型。
立体感来自箱体侧面、石材分面、台座厚度、透视地面投影、前后队员层次与墙体遮挡。
投影保持在地面，不跟随身体漂浮。局部动画幅度有限，默认不动。
四区添加水晶碎石、蕨叶、书堆、裂纹陶罐；墙面还有铭纹、排水栅和裂缝。
装饰点由坐标哈希确定，避开事件/地标/起点，不改变格子可通行性，不生成新掉落或敌人。

## 测试与边界

新增 `tests/rendering.test.mjs`：44 项本地 Node 测试通过，覆盖资源尺寸、十类剪影、
保存兼容、确定性装饰、遮挡、投影、增援/撤退后成员显示、标记避让与局部动画。
新增 `tests/render_browser.py`：60 项本地 Chromium 检查通过，覆盖真实离线构建中的模块，
不是另写一套演示渲染器。记录在 `docs/visual-v021-results.json`。

四个旧资源的完整 SVG 与新栅格缓存逐像素比较误差为 0；18 种资源/屏幕边缘组合的
遮挡后像素与独立预期蒙版一致。隔墙前后整个画面一致，含图标；没有 JavaScript 错误或外部资源请求。
测试还覆盖四方位/斜视、360/390/768/1200 宽度、DPR 1/1.5/2、实际 1440/390px 游戏 UI、
减弱动态、动画开关及帧渲染不修改游戏状态。旧裁切代码在同环境中的误差另外记录，
但不要求其他浏览器也必须重现旧浏览器缺陷。

现有 GitHub Node 全量测试由 CI 独立执行，不把本地新增测试当作原有 143 项已在本地重跑。
新工作流 `.github/workflows/visual-regression.yml` 在相关 PR 与 main 推送时执行像素检查，
只读仓库权限，截图保留于私密仓库的 Actions artifact 7 天。构建同步工作流不变。

测试使用内存 HTML / Storage 替身和指定场景。未验证真实 iPhone Safari、原生 file: 存储、
低端设备性能和长时间眩晕感受。截图为生产渲染器的场景夹具，不是自然跑局刚好遇到的布局。
本轮没有完成新一轮数值平衡，也没有修改那部分规则。
