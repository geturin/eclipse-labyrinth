## 浏览器实测

可选测试脚本：`tests/browser_smoke.py`。使用本地 Chromium、Python Playwright，对**构建后的单文件游戏**执行了 **57 项检查，全部通过**。输出保存在 `docs/browser-smoke-results.json`。

测试页面在浏览器内存中加载，不经过外部网址；Storage 使用内存测试替身。在这一环境中：

- 六职业选择、空队伍禁止开始、最多三人、单人说明、输入种子正常。
- 实际通过按键走到早期宝箱，调查、三选一、选择武器持有者、交换旧武器正常。
- 地图/行囊打开关闭、模态背景 inert、暂回标题再继续、覆盖存档确认与新局重置正常。
- 用**未提高角色属性**的首层遭遇，通过真实 UI 完成战斗胜利及领赏。
- 单体治疗选人、取消不消费、休息恢复、强制事件不能用 Escape 跳过正常。
- 1440px 桌面，以及 360px、390px、768px 视口下，标题、探索和战斗没有页面横向溢出；窄屏移动及攻击按钮操作通过。
- 捕获到的 JavaScript 未处理运行时错误为 0；外部运行时网络请求为 0。

`docs/screenshots/` 中为真实浏览器截图，不是概念稿。桌面探索展示用种子为 `MOON-0006`；战斗示例为 `FIRST-LIGHT`。

### 不代表已经验证的内容

内存 Storage 测试验证的是保存/读取调用与游戏恢复流程，**不代表验证了真实文件 URL、隐私模式、iOS Safari 或浏览器策略下的存档持久性**。引擎层另外有真实 JSON 序列化往返测试，但同样不能替代这些平台验证。

窄屏 Chromium 不是真实 iPhone 或 Android 设备。尚未进行 Firefox、Safari、真实触屏、低端设备性能、后台音频生命周期和完整无障碍审计。音频采用点击后启动、默认静音；合成音频的实际听感没有在本次自动化中作专业评审。

尚未进行长时间真人游玩、大规模五层胜率模拟或职业/掉落组合的完全平衡。部分 UI 很小的说明在手机上缩略，完整规则可在职业图鉴、说明与武器面板读取。
