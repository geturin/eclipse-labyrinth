# v0.3.1 · 下半区 UI 精简

## 如何使用

下载 `dist/index.html` 直接打开。标题版本为 0.3.1。
沿用 v0.3 的 `eclipse-labyrinth.run.v3` 存档，不要求新局；不同离线文件路径能否共享
原有存档仍取决于浏览器。本轮没有改动战斗引擎、职业数值、CD、地图生成或怪物 AI。

## 新布局

人物状态卡是唯一的战斗角色选择入口，不再另设一排角色名字。点击卡片选择该角色的技能；
治疗或复活选目标时，同一张卡片变成目标选择入口。HP、异常状态、防御姿态和可用技能数仍在卡片上。
倒下的角色不能施法；复活选择时只允许选择倒下角色。

下半区由条件出现的 Boss 预兆、人物卡、技能/道具区域、操作按钮构成。宽屏把技能和操作按钮
放在同一行；手机的五个已学技能也保持一行。主要指令使用 13～15px 字号，没有把旧面板整体缩小。

技能卡只保留名称、图标、强化/觉醒标记与就绪/剩余冷却；完整技能、武器、职业被动及状态通过
「详情」阅读，桌面还可悬停查看技能提示。冷却中的技能也能在详情中阅读，手机无需依赖悬停。
「道具」把同一技能区域切换成三种补给，而不是再增加一排常驻栏；此时「详情」显示完整道具说明。
防御、道具、详情和全队攻击保持在同一操作区。

Boss 当前预兆的截止回合、应对方式与解除进度始终显示，不折叠关键危险提示。
非当前预兆的首领特性、后续血线、敌方说明、附近队伍动向、地图与撤退放入战场右下角的「战况」。
存在近距巡逻、警报集结或精英时仍显示紧凑动向提示；不再常驻一整栏“没有增援”和反复的规则教程。
桌面行动记录默认折叠，手机收起常驻侧栏；探索菜单仍能打开行动记录，地图、工具、行囊也均有入口。

键盘：[ / ] 切换并聚焦队员，3～7 使用技能，1 提交全队攻击。焦点不在按钮时 Enter 也提交攻击；
焦点在按钮上时 Enter/Space 保留原生按钮操作，避免键盘选择队员时误提交回合。
选择、查看、切换道具栏和取消目标不消耗时钟、CD 或物资。动画锁定和跳过规则保持不变。

## 实测范围

本地 Node 测试 188/188 通过，包含 750 张地图连通性检查。
既有浏览器套件：探索像素 60 项、战斗与工具 34 项、完整冒险流程 96 项，均通过。
新增 `tests/compact_browser.py` 102 项通过，共 292 项浏览器检查。
涵盖 360/390/768/1440px、普通战/首领战、实际角色卡选择、治疗/复活、冷却、免费道具、防御、
完整说明可达、键盘焦点、原生 Enter、全局攻击快捷键、Boss 提示、日志与宽度溢出。
没有发现 JavaScript 运行错误或外部资源请求。测试使用真实静态构建和指定引擎场景，存储是内存替身。
GitHub CI 独立执行上述规则及四套浏览器测试，是否通过以远端实际结果为准。

## 与 v0.3 的同场景比较

比较范围为战场下方完整控制区（旧版指令栏至人物卡底部；新版整体操作区），不含主战场。
本地同一 Chromium、同一预兆/五技能/三人队伍场景：

| 场景 | v0.3 高度 | v0.3.1 高度 | 减少 |
|---|---:|---:|---:|
| 1440px 首领战 | 704px | 276px | 约 61% |
| 390px 首领战 | 1092px | 335px | 约 69% |
| 390px 普通战 | 766px | 267px | 约 65% |

完整测量见 `docs/ui031-results.json`。这些是固定场景与字体环境的布局测量，不代表任意状态、
字体缩放和设备都会有同一高度。场景为检查界面使用提高 HP 的测试存档，不表示实际难度/伤害。
没有重新宣称全职业长期平衡、真实 iPhone Safari、原生 file: 存储、低端性能或眩晕改善已经验证。
