# 月蝕の迷宮 · Eclipse Labyrinth

**v0.2.1 — 探索表现修复版**。原创日式幻想风格、第一人称格子迷宫、JRPG 回合战斗，
1～3 人小队，五层随机地牢。浏览器离线运行，无账户、无后端、无遥测、无素材下载。
每局等级、武器、祝福、习得技能和觉醒全部从零开始；只保存正在进行的这一局。

## v0.2.1 探索修复

修复怪物与物件只显示碎片的问题；新增独立探索造型、精英/守卫识别、远距图标和四区装饰。
菜单可独立开启轻微物件动画，默认静态舒适，系统减弱动态优先。v0.2 存档格式兼容。
具体改动和验证边界见 [探索修复记录](docs/VISUAL_V021.md)。

## 直接玩

下载仓库里的 **`dist/index.html`**，保存后用浏览器打开。它是完整静态游戏，
不是需要开发服务器的源码入口。仓库根目录的 `index.html` 是开发入口。
**私密仓库不等于线上网站**；本项目没有开启 Pages 或任何公开部署。

旧 v0.1 存档未删除，但 v0.2 规则不兼容，必须开始新一局。

## 这一版改变了什么

| 系统 | v0.2 实现 |
| --- | --- |
| 资源压力 | 普攻只回 1 MP，防御回 3 MP；施法职业普攻仅使用 55% 魔力。升级和战后不再大量回满资源，祝福和熟练度有上限。 |
| 职业分工 | 6 个职业各有两个起手技能、三个局内习得的高阶技能。不是每个人都能治疗、群攻和保护。 |
| 构筑成长 | 18 个可学习高阶技能，部分 B2/B3 开放；12 个初始技能机制觉醒。三选一奖励优先保证一项当前可选的新技能或觉醒。 |
| 敌方小队 | 10 个基础敌人模板：标记与追猎、护卫与治疗、强化与重击、反甲、魔镜、有限召唤等。 |
| 首领 | 5 套专属强化与回合/血线预兆。驱散、封头、清侍从、累计命中或防护；提示条件和结算回合。 |
| 明雷与增援 | 地图小队按格移动；玩家每走一步或等待，小队也行动一次。战斗每回合末，路径 8 格内敌人移动一格，抵达后下一轮参战。 |
| 迷宫辨识 | 每层四个不同材质区：银纹前厅、苔辉水道、残星书室、赭石遗庭。地标、区域编号、房间大小、回廊与地图色块辅助定位。 |
| 舒适模式 | 默认即时移动/转向，固定镜头，关闭闪屏和漂浮粒子。菜单可以切回平滑移动；不是消除所有眩晕的医学保证。 |

装备仍然**只有武器**，18 把武器，每把一个固有效果，可换给任何职业。
另有数量有限、全队共享的急救药/以太滴/破咒盐，使用占一次行动；它们不是装备槽。

## 职业与局内方向

| 职业 | 起手职责 | 可习得的高阶能力 |
| --- | --- | --- |
| 星刃骑士 | 破甲、全队壁垒与吸引攻击；没有治疗 | 反击阵、全队拦截、群体破甲剑阵 |
| 焰咒魔导师 | 火冰弱点、燃烧后融解；脆弱且依赖 MP | 火系群攻、双重咏唱、三段雷锁 |
| 祈星巫女 | 单体治疗、全队净化；攻击不再免费回血 | 驱散攻击、复活、治疗/净化圣域 |
| 影缝忍者 | 剧毒、封头；打断敌方配合 | 封腕、三段追击、残影诱饵 |
| 刻时术士 | 迟缓、单体加速；没有治疗 | 双重驱散、预兆延期、队友技能回声 |
| 血誓剑士 | 伤害吸血、换血回蓝；不照顾队友续航 | 群体收割、损血爆发、一次不归保命 |

初始技能熟练度达到 +1 后，奖励池会加入它的机制觉醒。例如加速变全队、
治疗溢出转护盾、毒素传播、裂刃变双段、碎星斩附带驱散。
熟练度最多 +2：伤害/治疗每级 +12%；非伤害支援技能每级降低 1 MP（最低 1）；
血之契约每级额外回 2 MP。独行仍有 HP/MP/伤害补偿，但现在是高风险挑战。

## 操作与战术

W/S 前后、A/D 转向、Q/E 平移、Space 等待、F 调查、M 地图、I 行囊。
战斗按 1 普攻、2 防御、3～7 职业技能；也支持触控。点击敌人查看意图和应对说明。
转向、撞墙、阅读地图和界面不会推进世界时钟。

选择开战地点：红色菱形是明雷，金色是强敌；声音提示是最短路径距离，不保证
所有小队都能在该回合抵达，其他怪物可能挡路。最多 6 个存活敌人同时参战，
满员时其余小队等待。最后一个击杀结束的未完整回合也结算一次附近移动。

读预兆再行动：血线不会在命中瞬间偷袭，下一次可用回合先给完整应对窗口。
血线存在一次相位锁；未结算的血线预兆保护最后 1 HP。防御不能移除强化，
延期也不等于取消。首领第 13 回合起逐轮增伤，不能靠无限防御永久拖延。

## 开发、测试与静态构建

要求 Node.js 20+；项目没有 npm 依赖。

```sh
npm test
npm run build
npm run verify:dist
npm run dev
```

`npm run dev` 的地址以终端输出为准；`npm run build` 生成自包含的
`dist/index.html`。**每次改源码，都把该文件一起提交并推送。**
GitHub 工作流会运行测试/构建，PR 检查静态页是否陈旧，普通分支 push 则会自动
补交遗漏的静态页。不强推，不启用公开托管。`AGENTS.md` 约束后续代理同样遵循此流程。

首次创建仓库的旧脚本 `npm run publish:private` 仍保留；本仓库已经存在，更新时
不要再次调用它创建仓库。更多说明见 `docs/PUBLISH.md`。

可选：`npm run balance` 运行固定策略的隔离战斗比较；
`CHROMIUM_PATH=/usr/bin/chromium python tests/browser_smoke.py` 运行浏览器检查。
具体测试范围、限制和结果见 `docs/QA.md`。

## 文件

`data.js` 管内容；`world.js` 管地图和明雷；`engine.js` 管纯规则；
`app.js` 管界面；`renderer.js` 管视角；`art.js`/`audio.js` 管原创程序资产。
细节见 `docs/GAME_DESIGN.md` 与 `CHANGELOG.md`。

这是可玩的第二版，不是已经完成全职业/全种子长期平衡的商业成品。
真实 iPhone Safari、原生文件存储限制以及长期跑局反馈仍需实机验证。
